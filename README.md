# Kahani Coffee House — Web Technologies Assignment 01

A fully static, multi-page website built with only HTML, CSS, and JavaScript.
Theme: a fictional Lahore coffeehouse called **Kahani** ("story" in Urdu) — every
page and copy choice ties back to that storytelling idea.

## Folder structure

```
kahani-coffee/
├── index.html        Home page
├── about.html         About page (story, timeline, values, team)
├── menu.html           Menu / products page (filterable, hours table)
├── gallery.html        Gallery page (lightbox modal)
├── contact.html         Contact page (validated form + map)
├── css/
│   └── style.css       single external stylesheet, design tokens, Flexbox + Grid, responsive
├── js/
│   └── script.js        all interactive behaviour
└── images/               (reserved for real photos if you swap in your own)
```

## Pages and what they cover

| Page | Purpose |
|---|---|
| Home | Hero banner, highlights, menu teaser, testimonial slider, main navigation |
| About | Founding story, timeline (sequence → numbered markers), values, team |
| Menu | Full product listing with **JS category filter**, opening-hours table |
| Gallery | Photo-style tile grid with a **JS lightbox modal** |
| Contact | Contact form with **JS live validation**, address, hours, embedded map |

## JavaScript interactive features (5 total)

1. **Responsive hamburger navigation** — nav collapses under 600px, toggled by a button with `aria-expanded`.
2. **Menu category filter** — buttons dynamically show/hide `.menu-item` elements by `data-category`.
3. **Gallery lightbox modal** — clicking a tile opens a modal with details; closes on button, backdrop click, or `Esc`.
4. **Testimonial carousel/slider** — auto-rotates every 5s, with clickable dots generated by JS.
5. **Contact form validation** — checks name, email format, optional phone format, and message length; shows inline errors and a success message, all without a backend.

## CSS technical notes

- One external stylesheet (`css/style.css`) linked from every page.
- CSS custom properties (`:root` variables) define the whole colour/type/spacing system.
- Layout uses **Flexbox** (nav, footer, hero actions, filter bar) and **CSS Grid** (highlights, menu grid, gallery grid, team grid, footer grid).
- Responsive breakpoints at `900px` (tablet) and `600px` (mobile) reflow grids to fewer columns and switch the nav to a hamburger.
- Consistent header/nav and footer markup repeated on every page for a unified feel.

## HTML technical notes

- Semantic tags throughout: `header`, `nav`, `main`, `section`, `article`, `footer`.
- A `<table>` is used for opening hours (genuinely tabular data).
- A `<form>` with proper `<label for>`/`<input>` pairing is used on the Contact page.
- Every page shares the same nav and footer markup, with `aria-current="page"` marking the active link.
